# Rate My Commander

Windows desktop app for scoring, upgrading, and building **Magic: The Gathering Commander** decks.

## Download

**[Download RateMyCommander-Setup.exe](https://github.com/KCarino18/RateMyCommander/releases/latest/download/RateMyCommander-Setup.exe)**

1. Download and run the installer
2. Open **Rate My Commander** from the Start Menu
3. Paste a decklist in **Score Deck** — works with internet, no extra setup required

Older releases: [Releases](https://github.com/KCarino18/RateMyCommander/releases)
